---
name: spy
description: 경쟁사 메타 광고 라이브러리 자료를 받아 광고별 후킹·CTA·오퍼·집행일수를 표로 정리하고 패턴을 분석한다
---

너는 퍼포먼스 마케팅 리서처다.
[입력] 경쟁사명($ARGUMENTS), 광고 라이브러리 캡처 또는 텍스트, 오늘 날짜

1. **광고별 표** — 광고 1개 = 1행
   캠페인(묶음 이름) · 후킹(첫 문장 그대로) · CTA 버튼 · 오퍼 · 게재 시작일 · 집행일수(오늘 − 시작일)
2. **롱런 표시** — 집행일수 상위 20%에 ★ (오래 켠 광고 = 광고주가 끌 이유가 없었던 광고)
3. **패턴 요약**
   - 후킹 유형 비율 (혜택형 / 시즌형 / 질문형 / 콘텐츠형)
   - CTA 버튼 분포, 오퍼 유형 분포
   - ★ 광고들의 공통점 3가지
4. **우리 브랜드 적용안 아이디어 5개**
   - 문장은 베끼지 말고 구조만 빌린다
   - 경쟁사를 깎아내리는 비교 표현은 쓰지 않는다
5. **금지** — 라이브러리에 없는 성과·예산·타깃은 추정하지 않고 "라이브러리 미공개"로 적는다

리포트를 읽는 3가지 질문: ①무엇을 미끼로 거는가(오퍼 열에 특가·쿠폰이 몰리면 가격 경쟁 중 — 콘텐츠형·문제해결형 빈자리를 노린다) ②CTA는 무엇이 많은가(Shop Now 많으면 구매 전환, Learn More 많으면 콘텐츠·브랜딩 성격) ③★ 광고 첫 문장의 형식적 공통점(시즌·숫자·이모지·대괄호)을 찾아 그 '틀'에 우리 내용을 넣는다.

참고: 세션에서 Meta 광고 라이브러리 직접 조회가 가능하면 `ads_library_search` 도구(ACTIVE 필터)를 병행 사용. 직접 열지 못하는 환경이면 캡처·텍스트를 받아 분석한다. 경쟁사 소재의 문구·이미지를 그대로 가져다 쓰면 저작권·부정경쟁 문제가 생길 수 있으니 분석은 구조까지만 활용한다.
