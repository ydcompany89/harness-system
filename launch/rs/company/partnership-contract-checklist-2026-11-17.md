# 라파(최재호) × 알앤디메이커스(신동규) 동업계약 — 대표 메모 + COO 보완 (2026-11-17, 금요일 11/20 미팅 준비)
> 상태: 내부 준비 자료. 계약 조항·세무·보조금 관련은 변호사·세무사·전담기관 확인 후 확정 (L3).

## 대표 메모 (원문 요지)
- 라파가 제조 이익을 받듯 알앤디도 마케팅 이익(개당 수수료)을 받아야 영업이익 5:5가 성립. 없으면 배당율 조정.
- 제조원가 비교 / 재료비 1,300만 지급 / 시사출·조립비 2,000만 중 1,000만 회수 / 워킹화·인솔 완제품 500개 상계 여부
- 거래 마감 시 재고 등 청산 방법 / CS 범위·오배송·발주 확인
- 금요일 전 준비: 원가표 · 요청 내역 · 동업계약서

## COO 보완 (핵심)
1. 이익 구조 대칭: (A) 양쪽 다 마진 후 잔여 5:5 (B) 양쪽 다 원가 공개 후 5:5 — 둘 중 하나. '영업이익' 정의(차감 항목·광고비 부담 주체) 명문화.
2. 🔴 보조금: 재료비 1,300·시사출비 2,000이 도약 과제 집행분이면 '1,000 회수'·'완제품 상계'는 환수·용도 외 사용 위험 → 전담기관 확인 전 계약서에 넣지 말 것. 금형은 알앤디 소유(중요재산), 계약서에는 보관·사용 조항만.
3. 상계 단가 명시: 500개를 원가로 치면 약 300~500만 → 1,000만에 못 미침. 단가·잔액 처리 방법 필요.
4. 추가 조항: 지재권 귀속(상표·특허·디자인=알앤디), 독점·경업금지(양방향), 공급가 변경 절차(원가 공개·연 1회), 품질·불량·리콜·PL보험, 납기 지연, 정산 주기·장부 열람권, 의사결정(L3 목록)·교착 해소, 기간·해지·청산(재고 매입가·금형 반환·판매 유예기간), 신규 법인(양주) 승계, 적용 범위(RS만, re.feeel 제외), B2B·수출 건 처리, 비밀유지.
5. 법적 형태: '동업계약'=민법상 조합(연대 책임) 위험 → '공동사업 약정 + 제조공급 계약' 2건 분리 또는 신설 법인 주주간계약. '배당' 용어는 법인 설립 전엔 '이익 정산'.
6. CS: 오배송·불량=라파 귀책 시 라파 부담(왕복 택배비+재출고), 발주서 서면 확인(수량·색·사이즈·납기) 24시간 내 회신.

## 정정 (11/17 대표): 라라슈 법인은 이미 설립됨 → 계약 구조 변경
- '동업계약(조합)'이 아니라 **법인을 가운데 둔 계약 4건**으로 정리:
  1. 주주간계약 (신동규·최재호): 지분·의사결정·배당·지분 양도 제한·교착 해소·청산
  2. 제조공급 계약 (라파 → 법인): 공급가·원가표·품질·납기·오배송
  3. 마케팅·판매 용역 계약 (알앤디 → 법인): 개당 수수료 또는 매출 대비 요율 — 대표가 원하는 '마케팅 이익'의 자리
  4. 지재권·금형 사용 계약 (알앤디 → 법인): 상표·특허·디자인·금형은 알앤디 소유, 법인에 사용 허락
- '배당' 용어 사용 가능(법인 이익 → 주주 배당). 2·3번은 특수관계인 거래라 시가 기준 필요(세무사 확인).
- 확인 필요: 법인명·등기일·지분율·대표이사·자본금 납입 주체, 판매 주체(자사몰·와디즈 사업자)가 법인인지 알앤디인지, 상표 출원인 명의.

## 대표 확인 (11/17) 및 쟁점
- 법인 등기 2026-10-30 · 지분 5:5(자본금 각 1,000만) · 대표이사 최재호 단독 · 판매는 알앤디 명의 · '라라슈' 상표 출원인 = 최재호 · 재료비 1,300만·시사출비 2,000만 = 정부지원금
- 🔴 쟁점 1 (보조금): 1,000만 회수·완제품 500개 상계는 계약서에 넣지 않는다. 회수금은 반납 대상일 수 있음 → 전담기관(KEIA) 문의 후 처리. 금형·시제품을 법인이 쓰면 사용 승인 필요 여부 확인.
- 🔴 쟁점 2 (상표): 브랜드 핵심 자산이 상대방 명의. 기존 기록(log 10월 "명의: 특허·판매 모두 알앤디 유지")과 다름 → 출원인 확인 후 법인 이전 또는 알앤디 공동 출원/전용사용권 + 해지 시 귀속 조항.
- 🔴 쟁점 3 (돈의 흐름): 매출은 알앤디, 대표이사는 최재호, 법인엔 매출 없음 → 5:5 배당할 이익이 법인에 안 생김. 
  - 1단계(과제 기간): 알앤디 판매 유지 + 알앤디↔라파 '이익 정산 약정'(마케팅 수수료·제조 마진 차감 후 5:5)
  - 2단계(과제 종료·승인 후): 판매를 법인으로 이관 + 계약 4건
- 지배구조: 5:5인데 대표이사 단독 → 신동규 사내이사 등재 또는 공동대표, 주주간계약에 사전 동의 사항(L3 목록) 명시.
