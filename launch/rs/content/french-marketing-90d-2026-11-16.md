## 0. 한 줄 원칙
**더 많이 알리지 말고, 더 갖고 싶게.** — 할인·물량·화제성 대신 **취향·절제·진짜 사람**으로 "일하는 신발에도 품위가 있다"를 보여준다.
- 레퍼런스 정신: 프랑스 작업복 **블루 드 트라바이(bleu de travail)** — 노동자의 옷이 스타일이 된 사례. 라라슈 = **서서 일하는 사람의 신발이 스타일이 되는 브랜드.** (타 브랜드 로고·이미지 사용 ✗, 개념만)

## 1. 라라슈 취향 정의 (대표 확정 필요 · L3)
| 남긴다 | 뺀다 |
|---|---|
| 색 2개: 차콜그린 + 라임(포인트만) | 무지개색 배너, 형광 할인 스티커 |
| 실제 사람의 손·발·작업장 (동의 받은 실물 사진) | AI 연출 이미지 위주 피드, 과한 합성 |
| 짧은 문장, 여백 | 이미지 안 글자 3줄 이상, 느낌표 |
| 만드는 과정(금형·시사출·수정) | "최저가·파격·역대급" |
| 정가 판매 · 선착순 한정(넘버링) | 상시 쿠폰·1+1·타임세일 |
| 대표의 목소리(스레드) | 레오 사장 B급 콘텐츠 → **월 1회 이하로 축소** |
| 비트컷 편집 리듬(억지 자막 없이) | 밈·유행 음원 따라하기 |

### 캡션 톤 예시 (감수 전)
- "빼고, 남긴 것."
- "출근부터 퇴근까지, 한 켤레로."
- "서서 일하는 사람의 신발에도, 품위가 있습니다."
- "깔창이 자꾸 딸려 나와요." — 그래서 깔창을 없앴습니다.
- 금지 유지: 통증·피로·교정·의사 추천·방수/미끄럼 단독 주장·친환경

## 4. 광고비 운용 (감성 60 : 효율 40)
| 구분 | 비중 | 내용 | 판단 지표 |
|---|---|---|---|
| 브랜드 | 60% | 메타: 매니페스토 필름·화보 도달 (서서 일하는 직군 + 일산·고양) | 3초 유지율, 저장·공유, 프로필 방문 |
| 효율 | 40% | 네이버 검색·쇼핑("라라슈"·"주방화"·"식당화") + 메타 재방문자 | 켤레당 광고비 ≤ 24,000원(손익분기) |
- 총액·월별 배분은 대표 확정 (월 300만 원↑ 시 L3)
- 할인 광고 소재 금지(정가 원칙). 와디즈 얼리버드는 플랫폼 관행으로 예외

## 5. 성과 지표 — "프랑스식" 숫자
| 지표 | 의미 | 3개월 목표(제안) |
|---|---|---|
| **정가 판매 비율** | 할인 없이 팔린 비율 | 90% 이상 |
| 네이버 "라라슈" 브랜드 검색량 | 이름을 기억하고 찾아온 사람 | 월 1,000회 |
| 직접·검색 유입 비중 | 광고 없이 오는 사람 | 자사몰 유입의 40% |
| 저장·공유 / 도달 | 갖고 싶다는 신호 | 3% |
| 재구매·추천 주문 | 팬 | 주문의 15% |
| (바닥선) ROAS | 망하지 않는 선 | 176% 이상 |
