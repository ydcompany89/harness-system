# 인스타 계정 분리: 라라슈 공식 vs 레오 (2026-11-18 대표 지시 · 초안)
> 근거: 프랑스식 3개월 계획(공식은 절제·실물) · 브랜드 캐즘(레오 = 사람을 모으는 B급 숏폼) · 인쇄물·랜딩에 박힌 주소는 @rharashoe
> 상태: 초안. 계정명·프로필 문구는 대표 확정, 게시 문구는 rs-compliance.

## 역할 한 줄
- **공식(@rharashoe)** = 매장. 믿고 사게 만드는 곳.
- **레오(새 계정)** = 전단지 돌리는 사장님. 웃기고 공감돼서 따라오게 만드는 곳.

| | 라라슈 공식 @rharashoe | 레오 사장 (새 계정) |
|---|---|---|
| 퍼널 위치 | 설득·전환 (살까 말까 하는 사람) | 유입 (라라슈를 모르는 사람) |
| 말하는 이 | 브랜드 (1인칭 '저희') | 레오 사장 캐릭터 (반말 섞인 사장님 말투) |
| 톤 | 절제·실물·여백 (브랜드 북) | B급·공감·유머 |
| 콘텐츠 | 제품 실물, 만드는 과정, 사장님 한마디→고친 것, 시험 결과, 오픈·펀딩 소식 | "서서 일하면 다 아는 그 순간" 공감 릴스, 현장 상황극, 밈 |
| 형식 | 피드 3:4 갤러리 + 다큐 톤 릴스 | 릴스 위주 (비트컷 15초) |
| 주 발행 | 피드 3 · 릴스 2 | 릴스 3~4 |
| 제품 노출 | 매 게시물 | 3편 중 1편만, 끝 2초 (광고 냄새 줄이기) |
| 행동 유도 | 프로필 링크 → 랜딩·와디즈·자사몰 | "신발은 @rharashoe" 태그 → 공식으로 넘기기 |
| 광고 집행 | 여기 게시물로만 | 광고 안 함 (반응 좋은 릴스만 공식에서 협업 게시물로) |
| 고객 문의·DM | 여기서 응대 | "문의는 @rharashoe로" 안내만 |
| 성과 지표 | 프로필 링크 클릭, 저장, 와디즈·자사몰 유입 | 도달, 공유, 공식 계정으로 넘어간 방문 수 |

## 넘나드는 규칙
1. 레오 → 공식은 태그·협업 게시물로 연결. 공식 → 레오는 스토리 공유 월 1~2회만.
2. 공식 그리드에 레오 캐릭터 이미지는 올리지 않는다 (톤 분리).
3. 가격·할인·오픈일은 공식에서만 말한다. 레오는 "자세한 건 공식에서".
4. 두 계정 모두 금지어 동일: 통증·피로·교정·의사 추천·미끄럼 단독 주장·친환경. 레오 말투여도 효능 약속 금지.
5. 레오 프로필에 "라라슈가 운영하는 AI 캐릭터 계정" 표기. 협찬·체험단 게시물은 [협찬].
