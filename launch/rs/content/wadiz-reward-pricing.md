# RS 라라슈 와디즈 리워드 가격 구성안 (v1, 2026-10-04 · 대표 승인 전)

기준가(판매예정가, 10/02 대표 확정): 쿼드그립 종일편한 워킹화 **42,500원** · 쿼드그립 아치가득 인솔 **21,500원**
구조: **슈퍼얼리버드(수량 한정, 오픈 초반)** → **베이직(와디즈 펀딩가, 수량 제한 없음)**

### 설계 원칙 (왜 이 숫자인가)
1. **사다리 유지**: 세트일수록 1개당 싸지고, 같은 구성이면 슈퍼얼리버드가 항상 더 쌈.
2. **슈퍼얼리버드 긴급성 보호**: 베이직 세트의 1개당 가격(31,250~32,450)도 슈퍼얼리버드 단품(29,900)보다 비싸게 → "베이직 세트 사면 되지"로 새는 것 방지. 인솔도 동일(15,950 > 14,900).
3. **W4 '우리 가게 세트'**: 타깃이 식당 사장님 → 사장님 + 직원 3명. 객단가를 끌어올리는 핵심 리워드. 사이즈는 4족 각각 선택.
4. **I2**: 인솔은 일반 신발용 → "운동화 하나, 출근 구두 하나" 프레임.
5. **X1 주의**: 워킹화는 "깔창 필요 없는 일체형 안창"이 스토리. X1은 반드시 **"인솔은 가지고 계신 다른 신발용"**으로 설명 (워킹화에 넣으라는 오해 금지). 메시지 충돌이 걱정되면 X1은 빼도 됨.
6. 끝자리는 x,900 / 세트 대형은 만 원 단위로 깔끔하게.

## 2. 마진 확인 — 원가표(F03) 받으면 바로 판정
수수료 가정: 와디즈 수수료 15% + VAT = 16.5% (요금제별 상이 → 계약 요금제로 교체), 포장·출고 부담 3,000원/건(무료배송 시).

| 판매가 | 원가 상한 (마진 0) | 원가 상한 (마진 30% 확보) |
|---|---|---|
| 워킹화 29,900 (SEB) | 21,966 | 12,996 |
| 워킹화 33,900 (베이직) | 25,306 | 15,136 |
| 인솔 14,900 (SEB) | 9,442 | 4,971 |
| 인솔 16,900 (베이직) | 11,112 | 6,041 |
→ **인솔 단품 SEB가 가장 빠듯**. 인솔 원가가 5,000원을 넘으면 I1 SEB를 15,900으로 올리는 것을 권장.

구글 시트 수식 (A=판매가, B=원가, C=수수료율 0.165, D=건당 포장·배송 부담):
```
단위마진   =A2-B2-A2*C2-D2
마진율     =(A2-B2-A2*C2-D2)/A2
원가상한(목표마진 E2) =A2*(1-C2-E2)-D2
```
