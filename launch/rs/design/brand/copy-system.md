## 1. 브랜드 레벨
### Made for Standing.
- 영문 고정, 마침표 포함. 로고 락업: `RS · RhaRa Shoe · Made for Standing.`

### 발이 편해야, 일이 편하다.
- **2026-10-07 대표 확정.** 표기: **쉼표형 `발이 편해야, 일이 편하다.`** 를 기본으로, 포스터·행택처럼 두 줄로 끊을 때만 `발이 편해야. / 일이 편하다.`
- 쓰는 곳: 행택 바닥면·인솔 행택 문구칸, 상세페이지 히어로 서브, 박람회 부스 메인 현수막, 인스타 프로필 2행
- **같이 쓰기:** `Made for Standing.` 아래 한글 짝으로 붙여 쓰는 건 OK (같은 메시지의 번역 관계). `From Road to Floor.`와는 한 화면 금지.
- ⚠️ 가드: 이 문장은 **삶의 태도(격언)**로 쓴다. 바로 뒤에 "라라슈를 신으면 발이 편해집니다" 같은 **효능 약속을 붙이지 않는다.** (편안함 효능은 착화 시험 근거 없음)

### From Road to Floor.
- 한글 짝: 도로를 달리던 고무, 주방 바닥으로.
- 폐타이어 고무는 **그립 패드**에만 — "타이어로 만든 신발" ✗

## 2. 쿼드그립 종일편한 워킹화 (42,500원)
| 용도 | 카피 |
|---|---|
| **헤드라인** | **서서 일하는 사람의 신발은, 바닥부터 달라야 한다.** |
| 서브 | 깔창 없는 일체형 안창, 밑창 4점 쿼드그립 패드, 도톰한 발목 테두리. |
| 구조 ① | **쿼드그립 4점 패드** — 밑창 4곳에 그립 패드를 배치했습니다. 패드에는 폐타이어 고무를 새활용했습니다. |
| 구조 ② | **깔창 없는 일체형 안창** — E-실리폴리렌으로 안창까지 한 몸. 따로 빠지는 깔창이 없습니다. |
| 구조 ③ | **도톰한 발목 테두리** — 발이 들어가는 입구 테두리를 다른 부분보다 두껍게 둘렀습니다. |
| 한 줄 (썸네일) | 깔창이 없는 워킹화 / 바닥부터 다른 워킹화 / 4점으로 딛는 신발 |
| 한 줄 (광고·릴스 후킹) | "유니폼은 맞췄는데, 신발은요?" (B2B) · "사장님은 앉을 틈이 없으니까." (B2C) |
| 행택 표지 | 라라슈 쿼드그립 / **종일편한 워킹화** / QUAD GRIP — WORKING SHOE |
| 소재 문장 | 그립 패드 4개, 한때 도로를 달리던 고무입니다. |

## 3. 쿼드그립 아치가득 인솔 (21,500원)
| 용도 | 카피 |
|---|---|
| **헤드라인** | **신던 신발은 그대로, 바닥만 새로.** |
| 서브 | 가지고 계신 신발에 넣어 쓰는 아치 인솔. |
| 구조 ① | **아치가득 구조** — 발 아치 라인을 따라 가득 채운 형태로 설계했습니다. |
| 구조 ② | **뒤꿈치 컵 구조** — 뒤꿈치를 감싸는 컵 모양입니다. |
| 구조 ③ | **우드칩 배합 소재** — 목공소에서 나온 자투리 우드칩을 E-실리폴리렌에 섞었습니다. |
| 한 줄 (썸네일) | 신발은 그대로, 바닥만 새로 / 아치를 채운 인솔 |
| 한 줄 (스레드 역설) | 깔창은 없앴는데, 인솔은 만들었어요. (실측 조회 161 — 2위) |
| 행택 문구 | **발이 편해야, 일이 편하다.** (인솔 행택 문구 2번 자리, 기존 "발이 편해야 일이 편하다." 쉼표 추가) |
| 와디즈 | 인솔 단독 펀딩 메인 카피 후보: "신던 신발은 그대로, 바닥만 새로." |

> 왜 워킹화엔 깔창이 없는데 인솔을 따로 파나? → **인솔은 "가지고 계신 다른 신발용"** (워킹화에 넣는 용도 아님). 이 역설이 오히려 후킹 소재 (스레드 실측).
