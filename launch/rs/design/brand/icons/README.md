# RS 기술 배지 (Tech Badges)

행택·브로셔·상세페이지·박람회 부스·SNS에 공통으로 쓰는 육각 배지 아이콘 세트.

- 원본 데이터: `icons.mjs` (아이콘 형태·문구·사용 조건) → `node build-icons.mjs`
- 인쇄용 벡터: `svg/rs-badge-*.svg` (13종) · 전체 시트: `icon-sheet.png`
- 행택은 `../../hangtag/build.mjs`가 이 세트를 직접 불러 쓴다 (수정은 여기서 한 번만)

## 사용 규칙 (표시광고법)
| 상태 | 배지 | 조건 |
|---|---|---|
| ✅ 사용 가능 | 쿼드그립 4점 패드 · 일체형 안창 · 발목 라인 · 헤링본 · 폐타이어 고무 · 실크벽지 PVC · 우드칩 · 아치 라인 | 구조·소재 **사실 표기**만. 성능 수치·효과 문구 붙이지 않기 |
| 🔒 잠금 | 특허출원 · 디자인등록 | 출원·등록 **번호를 같이 표기**할 때만 |
| 🔒 잠금 | 미끄럼 시험 · 항균 시험 · 유해물질(프탈레이트) 시험 | **시험성적서 수령 후**, 기관·규격·결과를 함께 표기 |

- 참고 시안의 "ULTRA-GRIP", "FATIGUE REDUCTION"(피로 감소) 같은 최상급·효능 표현은 **쓰지 않는다**.
- "CXP ANTI-BACTERIAL"(항균)은 항균 시험성적서 없이는 사용 불가.
- 잠금 배지를 활성화하려면 `icons.mjs`에서 해당 행의 `'lock'`을 `'ok'`로 바꾸고 문구에 번호를 넣는다 → 트래커에 근거 문서 경로 기록.
