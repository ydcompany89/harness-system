# 카드뉴스 캡션 · 해시태그 (게시 전 대표 승인 L2)

> 해시태그 5개 원칙 (인스타 2개월 계획): 큰 태그 2 + 직업 태그 2 + 브랜드 1

## 01 신발 바꿀 때 됐다는 신호 5가지
```
하루 종일 서 있는 사장님, 오늘 퇴근하고 신발 한번 뒤집어 보세요 👟

밑창 무늬, 뒤꿈치, 깔창, 발목 입구 —
3개 이상 해당되면 바꿀 때가 된 거예요.

저장해 두고, 옆 가게 사장님께도 공유해 주세요.

#자영업자 #사장님 #주방화 #서서일하는직업 #라라슈
```

## 02 주방 바닥, 덜 미끄럽게 닦는 순서 5단계
```
열심히 닦았는데 바닥이 더 미끄럽다면, 순서 문제예요 🧽

기름기 걷기 → 세제는 표시 비율대로 → 맑은 물로 헹굼 → 물기 밀어내기 → 다 마를 때까지 동선 막기

오늘 마감은 이 순서로. 직원 단톡방에 공유해 두세요.

#자영업자 #식당운영 #주방청소 #식당사장님 #라라슈
```

## 03 10시간 서 있는 날, 3분 발 풀기
```
쉬는 시간 3분, 의자 하나와 벽 하나면 됩니다 🦶

발가락 쥐었다 펴기 · 발목 돌리기 · 뒤꿈치 들기 · 종아리 늘리기 · 발바닥 굴리기

저장해 두고 쉬는 시간에 같이 해 보세요.
※ 불편하거나 아프면 멈추고 전문의와 상담하세요.

#자영업자 #사장님 #발스트레칭 #서서일하는직업 #라라슈
```
