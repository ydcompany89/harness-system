## 파일 (out/)
- `*_art.pdf` = 인쇄용 (칼선 없음) · `*_dieline.pdf` = 칼선·접는선·안전선 포함 확인용 · `*_preview-N.png` = 미리보기
- 색 약속: **마젠타 실선 = 칼선**, 시안 점선 = 접는선, 초록 점선 = 안전선(인쇄 안 함), 주황 = 족자 시선 띠
- 인쇄소가 AI/별색 칼선 레이어를 요구하면 dieline PDF를 Illustrator로 열어 마젠타 선을 CutContour 별색으로 지정
- 원본 수정: `python3 build.py && node render.mjs` (폰트는 `fonts/`에 Noto Sans KR 400/700/900 — Google Fonts에서 받아 넣기, git 제외)
