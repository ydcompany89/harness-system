# TREATMENT — 라라슈 쿼드그립 종일편한 워킹화 런칭필름

스타일: Swiss Motion Graphics (Work Label 2026 색) · 1080×1920 세로 · 24fps · 22.5초 · 내레이션 없음(레이아웃 자막 + 음악·효과음)
제품 이미지는 09/30 시사출 실물 사진만 사용 (양산품과 다를 수 있음 고지).

## 1. 후보 구조 3개
1. **스펙 시트 스크롤** — 한 장의 세로 스펙 시트를 위에서 아래로 읽어 내려감. 정보는 깔끔하지만 제품 사진이 작아짐.
2. **분해 → 조립** — 완성된 신발을 패드·안창·테두리로 해체했다가 다시 조립. 실물 사진만으로는 해체 표현이 불가 (AI 렌더 필요) → 탈락.
3. **점 하나에서 시작하는 기능 목록 (선택)** — 라임 점 1개 → 4개(브랜드 도트이자 4점 패드의 예고) → 로고 → 기능 3장 → 엔딩. 도트 4개가 01장에서 실제 밑창의 패드 4개 위에 다시 떨어지며 "로고의 점 = 밑창의 패드"로 이어짐. 실물 사진을 크게 쓰고 구조 설명만 함.

선택: **3**. 오프닝 이미지(점 하나)와 01장의 패드가 같은 기호라 기억에 남고, 성능 주장 없이 구조만 보여줄 수 있음.

## 2. 로그라인과 흐름
- 로그라인: 라임 점 네 개가 로고가 되고, 그 점들이 실제 밑창의 그립 패드 네 개 위에 내려앉는다.
- 설정: 점 → 로고 → 제품명 / 전환: 01 패드 · 02 일체형 안창 · 03 발목 테두리 / 끝: 음악이 반 마디 멈춘 뒤 종이색 엔딩카드, 11.11 OPEN.

## 3. 벤치마크
- 배울 것: 스위스 포스터의 그리드·좌측 정렬·극단적 크기 대비, 박자에 맞춰 착지하는 움직임.
- 배우지 않을 것: 데모의 구조·샷·악곡 (데모는 열어보지 않음), 화려한 키네틱 타이포(단어가 날아다니는 것).

## 6. 큐 맵
- 템포 120 BPM, 4/4, 2초 = 1마디. 모든 착지는 박에.
- 0–4초: 킥 없이 글로켄(사인파 말렛)만 점마다 한 음씩 (A–C#–E–A).
- 4–7초: 킥 4분음 + 클로즈드 햇 8분음 진입.
- 7–10.5초: 베이스 펄스(8분음, 배음 포함) 추가. 패드 링 착지마다 글로켄.
- 10.5–18초: 같은 그루브 + 장면마다 글로켄 모티프 한 음씩 높임 (빌드).
- 18.0–18.5초: 전부 정지 (반 마디 정적).
- 18.5초~: 엔딩 와이프와 함께 킥 1발 + 글로켄 화음, 이후 잔향만.
