# RS(RhaRa Shoe · 라라슈) 행택 인쇄 데이터 — 워킹화 / 인솔

상태: **초안 (사람 검토 필요)** · 인쇄 발주 전 `[확인필요]` 전부 해소 + 품질표시 1:1 대조 필수 (인쇄 후 수정 불가)

## 파일
| 파일 | 설명 |
|---|---|
| `hangtag-walking.html` / `hangtag-insole.html` | 원본 (mm 단위 CSS, `@page 240×180mm`). `?lines=0` 붙이면 칼선 제외 |
| `hangtag-{walking,insole}-dieline.pdf` | 칼선·접는선·안전선 포함본 (2페이지: 바깥면, 안쪽면) |
| `hangtag-{walking,insole}-nodieline.pdf` | 칼선 제외본 (아트워크만) |
| `hangtag-*-{outside,inside}-{dieline,nodieline}.png` | 미리보기 (300dpi 근사, 2835×2126px) |
| `build.mjs` / `hangtag.css` / `render.mjs` | 생성·렌더 스크립트 (`node build.mjs && node render.mjs`) — 수정은 여기서 |
| `fonts/` | Noto Sans KR 400/700/900, Noto Sans JP 400/700 (Google Fonts 다운로드, 약 35MB. 시스템에 Noto CJK 없어 로컬 임베드) |

## 전개도 치수 (mm)
- 한 칸(접힌 앞면) 55×110. 전개: 풀칠 날개 8 + 55×4 = 228 × 110, 하단에 바닥 55×55(둘째 칸 아래) + 끼움 탭 10mm(나머지 3칸, 사다리꼴).
- 페이지 240×180, 전개 원점 (6,6). 재단 여백 3mm, 안전선 3mm(녹색 점선).
- 행거 구멍 Ø5mm: 앞표지 칸 상단 중앙 (칸 상단에서 7.5mm).
- 접으면 55×55×110 정사각 기둥(연필꽂이). 칸 순서: 표지 → 명언1 → 명언2(바닥 붙은 칸 위) → 명언3.
- **안쪽면 페이지는 좌우 반전 배치**(양면 인쇄 시 뒷면에서 각 칸이 바깥면 칸과 정확히 겹치도록). 품질표시 칸이 안쪽면에서 왼쪽 끝에 보이는 것이 정상. 풀칠 날개는 안쪽면 우측.

## 칼선 / 레이어
- 마젠타 `#FF00FF` 0.25pt 실선 = 칼선(외곽 + 행거 구멍). 시안 점선 = 접는선. 녹색 점선 = 안전선(인쇄 제외용 가이드).
- 칼선본 PDF에서는 위 선들이 같은 페이지 SVG 위에 올라가 있음. 인쇄소가 별색/별도 레이어를 요구하면 `.cut` `.fold` `.guide` 클래스를 별도 레이어(별색 CutContour 등)로 변환 필요.
- 비교적 단순한 사다리꼴 탭 형태 — 실제 끼움 탭 각도/깊이는 시제품 접어보고 조정.

## [확인필요] 목록 (인쇄면에 빨간색 표기)
품질표시 패널 (워킹화·인솔 공통): 치수 / 색상 / 제조연월 / 제조국 / 주소 / 고객센터 / 바코드·분리배출표시
- 워킹화 재질: 갑피, 안창, 밑창, 그립패드 각각
- 인솔 재질: 본체, 패드 각각
- QR: "박람회 리드폼/홈페이지 연결 예정" 자리만 확보 (URL 확정 후 QR 삽입)

## 디자인/문구 중 사람 확인 필요 (인쇄면에는 빨간 표기 없음)
1. 일본어 번역(제품명·품목·취급 주의·항목명)은 직접 번역 — 일본어 검수 필요. 제조자명은 한국어 그대로(일본어/영문 상호 미확정).
2. "폐타이어 새활용 고무"가 제품 어느 부위(밑창/그립패드/갑피 등)에 쓰였는지 미확정 — 기능면·스토리면 문구 적용 부위 확인. "친환경/탄소감축" 표현은 쓰지 않음.
3. 인솔 "통기 도트", "뒤꿈치 컵", 워킹화 "원형 그립 패드 4개"는 시사출 실물과 대조 필요 (사실 기반 표현이나 형상 확인 안 됨).
4. 취급상 주의 문구(고온·직사광선, 젖은·기름진 바닥 주의, 용도 외 사용 금지 / 인솔은 화기·이상 시 중단)는 초안 — 법정 표시 요건과 대조.
5. 색: 네온 라임 `#C6F432`는 근사값 — **팬톤 확정 필요**. 배경 `#111111`은 리치 블랙 CMYK 별도 지정 필요(CMYK 변환 미실시, 현재 RGB).
6. RS 로고는 **임시 로고**(기하학 스트로크) — 실제 벡터로 교체. 한 곳(`build.mjs`의 `logo()`)만 바꾸면 전체 반영.

## 금지 표현 점검
미끄럼 방지/논슬립/충격 흡수/방수/균형 개선/교정/통증/재활용 함량 수치 — 미사용. 기능은 설계 사실 표현만.

## 인쇄소 전달 시 주의
- 현재 PDF는 RGB. CMYK 변환·라임 별색(팬톤 확정 후) 지정 필요. 폰트는 PDF에 임베드됨(아웃라인화 여부 인쇄소 확인).
- 종이: 350g 이상 재생지/크라프트 권장. 크라프트 사용 시 블랙·라임 발색 시험 인쇄 권장.
- 풀칠 날개 안쪽면은 무인쇄 권장(안쪽면 데이터에서 흰색 처리, 인접 3mm 블랙 재단여백만 존재).
- 최소 글자 크기: 품질표시 일부 3.9~4.5pt, 표지 영문 4.6pt — 인쇄 시안 실물 가독성 확인 필수 (필요 시 품질표시를 별도 스티커/뒷면 분리 검토).
- 접힌 후 정사각 기둥 형태이므로 앞표지 외 칸(명언면)이 연필꽂이 외부로 보인다.
- 안쪽면 PNG/PDF에서 행거 구멍은 칼선본에만 표시됨.

## 폰트 (git 제외)
`fonts/`(약 29MB)는 저장소에 올리지 않는다. 다시 렌더하기 전에 Google Fonts에서 Noto Sans KR(400/700/900)·Noto Sans JP(400/700) TTF를 받아
`fonts/NotoSansKR-400.ttf` 형식 파일명으로 넣는다 (`hangtag.css` 상단 @font-face 참고).
