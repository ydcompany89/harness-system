# 전문가(의사·한의사 등) 추천 섭외 가이드 — RS 조리화 · 쿼드그립 아치 인솔

> 벤치마크: 듀랩스 아치탭 상세페이지 "WHY?" 섹션 (한의사 자문이사 + 인용 코멘트)
> 원칙: **전문가 = 신뢰 장치**이지 **효능 보증 장치가 아니다.** 인솔·조리화는 의료기기가 아니다.

## 1. 누구를 섭외할까 (제품별 적합도)

| 유형 | 조리화 | 인솔 | 장점 | 주의 |
|---|---|---|---|---|
| 정형외과(족부) / 재활의학과 전문의 | ◎ | ◎ | "발·보행" 권위 최상 | 섭외비 높음, 효능 발언 조심 |
| 한의사 (구조·추나 계열) | △ | ○ | 듀랩스처럼 섭외 접근성 좋음 | 조리화(미끄럼·안전)와 연결 약함 |
| 물리치료사 / 운동처방사 | ○ | ◎ | 현장감, 비용 합리적 | "의사"급 권위는 아님 |
| 산업안전·인간공학 교수 / 산업보건 전문가 | ◎ | ○ | **급식실 산재 예방 = B2B·공공 명분**과 직결 | 소비자 인지도 낮음 |
| 현업 조리장·급식 영양사 (사회적 증거) | ◎ | ○ | 실착 후기 → DR 카피 최강 | 전문가 아님, 후기 형식으로 |

**추천 조합:** 소비자용 = **족부/재활 전문의 1명** + B2B용 = **산업안전 전문가 1명** + 체험단 조리사 후기(M03).

## 2. 법적 체크 (반드시)

| 항목 | 내용 |
|---|---|
| 의료기기 오인 | "아치 복원", "균형 개선", "교정", "통증 완화", "족저근막염" → **금지** (의료기기법상 공산품의 의료 효능 표방 금지). 듀랩스 문구를 그대로 따라 쓰지 않는다 |
| 추천·보증 심사지침 (표시광고법) | ① 전문가가 **실제로 제품을 써보고 판단**한 내용이어야 함 ② **대가 관계 공개** 필수 → "OOO 원장은 (주)알앤디메이커스 자문위원으로 자문료를 받았습니다" 명시 |
| 인용 근거 | "압력 분산 ○%" 같은 수치는 **족압 측정 시험성적서** 없으면 사용 금지 |
| 초상·명칭 사용 | 사진·이름·직함·소속 병원명 사용 범위와 기간을 계약서에 명시 |

### 허용 / 금지 문구 예시
| ❌ 금지 | ✅ 허용 (근거 있을 때) |
|---|---|
| 발 아치를 복원합니다 | 발 아치 라인을 따라 설계된 구조 |
| 족저근막염 예방 | 오래 서서 일하는 발바닥의 부담을 고려한 설계 |
| 전문가가 인정한 치료 솔루션 | ○○ 전문의가 직접 착용해보고 설계 방향을 자문했습니다 |
| 미끄럼 사고 예방 | (시험성적서 수령 후) 미끄럼 저항 시험 ○○ 기준 충족 |

(환경부 새활용 산업 육성 지원사업 수행 기업)

편하신 시간에 10분 통화 가능하실지 여쭙습니다.
