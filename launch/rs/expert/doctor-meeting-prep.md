# 정형외과 전문의 자문 미팅 준비 (2026-10-09 · 섭외 긍정 검토 단계)

> 상위 가이드: `../expert-endorsement.md` · 트래커 **M08** · 외부 전달용 브리핑: `doctor-briefing.pptx/.pdf`
> 원칙: **전문의 = 설계 자문(신뢰 장치), 효능 보증 아님.** 인솔·워킹화는 의료기기가 아니다 (C10).

---

## 1. 미팅 목표 (60분)
| 우선 | 받아올 것 |
|---|---|
| ① | **자문 수락 + 범위·조건 합의** (아래 3안 중 선택) |
| ② | 샘플 착용 후 **설계 피드백** (특히 패드 위치 · 뒤꿈치 · 아치 높이) |
| ③ | 상세페이지용 **코멘트·사진 사용 동의** + 사전 검수 절차 합의 |
| ④ | 일정: 코멘트 **10/24** · 상세 최종 반영 **11/3** (DP04) |

## 2. 진행 순서
| 분 | 내용 | 자료 |
|---|---|---|
| 0–5 | 인사 · 회사 소개 (새활용 제조사, 납품 이력) | 브리핑 2p |
| 5–15 | 왜 이 제품인가 — 하루를 서서 보내는 직업군 | 브리핑 3p |
| 15–30 | **샘플 직접 착용** (워킹화·인솔) + 밑창·단면 보여드리기 | 샘플 키트 |
| 30–45 | **설계 질문 7가지** (아래 4번) — 대표 메모 | 브리핑 6p |
| 45–55 | 자문 범위·조건·법적 가드 | 브리핑 7–8p |
| 55–60 | 다음 단계 · 계약서 초안 전달 일정 | 브리핑 9p |

## 3. 샘플 키트 (미팅 전날까지)
| 품목 | 수량 | 체크 |
|---|---|---|
| 쿼드그립 종일편한 워킹화 | **원장님 사이즈 1족 + 전시용 1족** | 사이즈 사전 문의 · **Q6 발입구 칩·Q7 뒤꿈치 파팅 없는 것으로 선별** |
| 쿼드그립 아치가득 인솔 | M · L 각 1 | **Q1 홀 뜯김 · Q2 찢어짐 · Q3 붉은 얼룩 없는 것**만 (양산 수정 전이면 "시사출 샘플" 고지) |
| 밑창 단면 샘플 / 패드 단품 | 1 | 일체형 안창·패드 끼움 구조 보여주기용 (공장 요청) |
| 소재 실물 | 폐타이어 칩 · 실크벽지 PVC · 우드칩 | 소재 질문 대비 |
| 인쇄물 | 브리핑 출력본 · 리플렛 · 회사 브로셔 · 명함 | design/fair-print · brochure |
| 시험 계획 | C02 미끄럼(KS M ISO 13287) · C09 반발탄성 의뢰 계획 1장 | "근거를 만드는 중"이라는 신뢰 |
| 무게 실측 | 270mm 한쪽 257g | 저울 사진 |

⚠️ 시사출 품평 🔴 이슈(Q1·Q2·Q3·Q6)가 남은 샘플을 드리면 첫인상이 "덜 된 제품"이 됩니다 — **최상품 선별**이 최우선.

## 4. 설계 질문 7가지 (대표가 직접 묻기 · 답은 내부 개선용 — 외부 인용은 원장 검수 후)
1. **패드 4점 배치** — 뒤꿈치 → 발 중간 → 발볼 → 앞꿈치 순서로 놓았는데, **뒤꿈치 후방(바깥 모서리)이 비어 있습니다.** 처음 딛는 지점이라 패드가 필요할까요? (내부 조사: `research/quadgrip-placement-evidence.md` — 간접 근거상 뒤꿈치 후방 우선)
2. **일체형 안창의 아치 높이** — 평발·요족인 분도 무리 없이 신을 수 있는 높이일까요?
3. **발볼(라스트 폭)** — 무지외반·발볼 넓은 분 기준으로 어떤가요? (P16)
4. **뒤꿈치 트임(클로그형)** — 장시간 서서 일하는 급식실·주방에서 괜찮은 형태일까요?
5. **아치가득 인솔** — 아치 높이·길이·뒤꿈치 컵 깊이 의견
6. **(콘텐츠용)** 오래 서서 일하는 분이 신발 고를 때 일반적으로 보는 기준 3가지
7. **(표현)** 상세에서 원장님 이름과 함께 쓰기 불편한 표현이 있다면?

## 5. 자문 조건 — 3안 (금액은 시세 확인 후 대표 결정)
| 안 | 범위 | 대가 | 장점 | 주의 |
|---|---|---|---|---|
| **A. 1회 자문 패키지** | 착용 평가 1회 + 코멘트 1~2문장 + 프로필 사진 · 1년 사용 | 1회 자문료 [  ]원 | 가장 빠름 · 부담 낮음 | 1년 후 갱신 협의 |
| **B. 연간 자문위원** (추천) | A + 분기 1회 설계 리뷰 + 신제품(조리화·주방화) 자문 + 콘텐츠 1편(인터뷰 영상/칼럼) | 연 자문료 [  ]원 (분할) | 2차 런칭(라라슈 12월)까지 연결 · 콘텐츠 자산 | 계약서 필수 |
| **C. 제품 협찬형** | 착용 후 의견만 | 제품 제공 | 비용 최소 | **협찬도 대가 → 공개 의무 동일**. 이름·사진 사용은 별도 동의 |

- 💰 **도약 과제 비목**(전문가 활용비 등) 해당 여부 확인 → 해당 시 **11/15 전 집행·증빙** (G01)
- 계약 핵심 조항: `../expert-endorsement.md` §4 (범위 · 매체·기간 · **사전 검수권** · 대가 공개 문구 · 종료 후 삭제 · 지급 시기)

## 6. 법·윤리 가드 (미팅에서 먼저 말씀드릴 것)
| 항목 | 내용 |
|---|---|
| 의료기기 오인 금지 | 교정 · 통증 완화 · 족저근막염 · 아치 복원 등 **의료 효능 표현 일절 사용 안 함** (C10) |
| 추천·보증 심사지침 | 실제 착용 경험에 근거한 의견만 · **대가 관계 공개**: "○○○ 원장은 ㈜알앤디메이커스 자문위원으로 자문료를 받았습니다" |
| 의사 윤리 | 의사가 특정 상품 광고에 '추천자'로 나서는 것을 제한하는 **의사협회 윤리지침**이 있는 것으로 알려져 있음 → 표현은 **"추천"이 아니라 "설계 자문"**으로, 원장님 측 확인 후 확정 |
| 의료기관 명칭 | 병원명 노출은 원장님 선택 (의료광고 오인 소지 → 기본은 "정형외과 전문의 ○○○"까지만) |
| 검수 | 모든 인용·사진은 **원장 사전 검수 후** 게시 · 수정 요청 시 즉시 반영 |

## 7. 활용 제언 — 어디에, 어떻게
**원칙: 히어로(첫 화면)에 의사를 올리지 않는다.** 첫 화면 의사 = 효능 보증처럼 읽힘. **"설계 이야기" 안에서** 신뢰를 보강하는 자리에 둔다.

| 채널 | 위치 | 형식 | 예시 문구 (원장 검수 전 초안) |
|---|---|---|---|
| **워킹화 상세** | CUT 08 "왜 4점인가" 바로 뒤 (신규 **CUT 08+ 전문의 자문**) | 프로필 사진 + 직함 + 인용 1~2문장 + 하단 대가 표기 | "발이 바닥에 닿는 순서를 고려해 패드 위치를 함께 검토했습니다." — 정형외과 전문의 ○○○ |
| **인솔 상세 / 와디즈** | 아치가득 구조 설명 블록 | 동일 | "아치 라인을 따라 채운 형태와 뒤꿈치 컵 깊이를 착용해 보고 의견을 드렸습니다." |
| **증거 모음 (CUT 23)** | 성적서·특허 옆 | "전문의 설계 자문" 칸 1개 추가 | 자문 사실 + 기간 |
| **콘텐츠 (유튜브·릴스·블로그)** | 교육형 1편 | "정형외과 전문의가 말하는 오래 서서 일하는 사람의 신발 고르는 기준 3가지" — **제품 효능 언급 없이 일반 정보**, 제품은 마지막 5초 | 검색·AI 노출(M15) 엔티티 형성에도 효과 |
| **B2B 제안서** | 급식실·병원 단체 구매 | "정형외과 전문의 설계 자문" 한 줄 + 자문 범위 | 공공·기관 구매 담당자 설득용 |
| **보도자료** | 런칭 보도 (11/11) | "전문의 자문을 거쳐 설계" 1문장 | 언론 인용 |
| **박람회** | 족자·POP는 이미 인쇄 → **테이블 스티커 1장**으로만 | "정형외과 전문의 설계 자문" | ⚠️ 부스에서 **"발 상담/진료"는 금지**(의료기관 밖 의료행위 소지) — 하려면 "토크"로 |

### 상세 반영 순서 (일정)
| 날짜 | 할 일 |
|---|---|
| 미팅 직후 | 질문 1~5 답 → 설계 개선 반영 여부 판단 (특히 뒤꿈치 패드 → C11 FTO·금형 일정과 함께) |
| ~10/17 | 계약서·대가 공개 문구 확정 |
| ~10/21 | 코멘트 초안 → 원장 검수 |
| ~10/24 | 확정본 + 프로필 사진 수령 |
| 10/27~11/3 | 상세 CUT 08+ · 23 반영 (DP03·DP04) |

## 8. 우리가 하지 않을 것
- "의사가 추천한 신발" / "전문의 인정" / "정형외과 의사도 신는" 류 ❌
- 원장 코멘트를 효능 문구와 같은 블록에 배치 ❌ (예: 코멘트 옆에 "피로가 줄어듭니다")
- 코멘트 문장 임의 편집 ❌ — 줄임표·발췌도 원장 승인
