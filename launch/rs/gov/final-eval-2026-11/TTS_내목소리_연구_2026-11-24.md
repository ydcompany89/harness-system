# 대표 목소리 TTS(보이스 클로닝) 연구 — 2026-11-24

> 목적: 최종평가 발표 영상의 내레이션을 대표 목소리로 TTS 생성 (대본 v2 그대로 읽히기)
> 원본: 드라이브 `[도약 알앤디메이커스]발표영상.mp4` (231MB)

## 결론
**가능합니다.** 대표 목소리가 깨끗하게 녹음된 **1~3분 분량**이면 즉시 복제(Instant Voice Clone)로 충분히 쓸 만한 품질이 나옵니다.
- 추천 1순위: **ElevenLabs 즉시 복제** — 한국어 자연스러움·속도 조절이 가장 안정적, 월 $6(스타터)부터
- 추천 2순위: **타입캐스트 내 목소리** — 한국 서비스, 한국어 억양 강점, 유료 플랜 + 본인 인증 필요
- 지금 연결된 도구(Higgsfield)에도 참조 음성 기반 TTS가 있어, 음성 파일만 있으면 이 작업 환경에서 바로 시험 생성 가능 (크레딧 차감, 견적 먼저)

## 진행 순서
1. **음성 샘플 준비** (대표 PC): 발표영상에서 잡음·음악 없는 구간 **1~3분**을 mp3로 잘라 저장 (10MB 이하 → 드라이브에 올리면 여기서 처리 가능)
   - 231MB 영상은 연결 도구의 파일 한도(10MB)를 넘어 여기서 직접 받을 수 없음
2. **복제 생성**: ElevenLabs(또는 타입캐스트)에서 본인 음성으로 '내 목소리' 생성
3. **대본 붙여넣기**: `대본_최종평가_7분_v2.md`의 구간별 문장을 그대로 입력 → 구간별 mp3 6개 생성
4. **속도 확인**: 구간별 길이를 표(1:00 / 1:30 / 2:30 / 0:30 / 0:30 / 1:00)와 맞춤. 숫자는 한글로 풀어 쓰면 발음 오류가 줄어듦 (예: "257그램", "9.6%" → "구 점 육 퍼센트")
5. **영상 합성**: PPT 화면 녹화 + 구간별 음성 (캡컷 등)

## 주의
- **평가 규정 확인 필수**: 발표 영상에 AI 음성 사용이 허용되는지 전담기관(평가 안내문)에 먼저 확인. 대표 본인 목소리 복제라도 "본인 발표" 요건이 있으면 실제 녹음이 안전
- 복제 음성 계정은 대표 본인 명의로 만들고, 음성 데이터는 다른 용도로 쓰지 않음 (사칭 방지)
- 생성 음성은 숫자·고유명사(리타이어렌, 라라슈, CXP)를 꼭 귀로 검수
