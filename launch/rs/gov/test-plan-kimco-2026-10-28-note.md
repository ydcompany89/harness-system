# 항균 시료 형태 메모 (2026-10-28)
- ISO 22196 시험편: 50×50mm 평판(두께 ≤10mm), 처리 시료 균주당 3개 + 무처리 대조 3개(균주 2종) → 처리 평판 6~10장 + 무항균 동일 배합 평판 6~10장 권장.
- 펠릿 원료 상태로는 시험 불가 → 연구원이 성형(프레스)해 줄 수 있는지 확인. 가능 시 예상 소요 1~2kg(평판 100×100×2mm 약 20g, 예비 포함). 단, 발포 EVA 실제품과 표면이 달라 결과 차이 가능 → 라파 실생산 조건 평판/안창 절단 시편 우선.
- 방취(가스검지관법) 시료 규격은 기관별 상이 → 견적 시 함께 확인.
