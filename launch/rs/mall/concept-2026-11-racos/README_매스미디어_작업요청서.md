## 4. 디자인 기준
- 색: 바탕 #F3F1EC · 히어로 #EFE7DC · 글자/짙은 바탕 #0D1B14 · 카드 #14281D · 강조 라임 #C6F432 · 보조 글자 #6B746E
- 글꼴: **Pretendard** (숫자 Poppins 허용) · 굵기 700 이하 — **웹폰트 연결 필수**(CDN 또는 파일). 시안 폴더에는 글꼴 파일이 없어 PC에 따라 다른 글꼴로 보일 수 있음
- 모서리: 카드 24px · 버튼 완전 둥근 알약형
- 동작: 곡선 cubic-bezier(0.22,1,0.36,1) · 스크롤 등장 0.7초(아래에서 32px) · 숫자 1.2초 카운트업 · 히어로 신발 6초 위아래 흔들림 · 쿼드그립 핀 2.4초 맥박 · `prefers-reduced-motion` 시 움직임 끔
