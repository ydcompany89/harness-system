## 3. 마케팅 방식 분석 (참고 포인트)

### 구조 공식
**신뢰 선제(배송·공식·미디어) → 공포소구 문제제기 → 수치 솔루션 → 3대 장점 → 타사 비교 → 업력/평점 → 공인 성적서 증명 → 극한 테스트 → 리뷰 → TECH POINT 넘버링 → 2차 문제제기(편안함) → 페르소나 후기 → 실사용 시연 → 룩북 → FAQ → 스펙**

- **두 개의 축을 순서대로 판다:** 앞 절반은 "안전(미끄럼)", 뒤 절반은 "편안함(장시간 서서 일함)". 각 축마다 문제제기→해결→후기 루프를 따로 돌림.
- **증명 계층이 3단:** ① 공인 성적서 숫자(0.82, KS M ISO 13287) ② 극한 연출 테스트(기름 경사로, 워터슬라이드) ③ 실사용 시연(실제 주방 점프). 숫자 → 재미 → 현실 순.
- **"1등급" 프레임 재정의:** 경쟁사도 다 1등급이라 말하니 "1등급(0.36)이 아니라 1등(0.82)"으로 기준선을 다시 그음. 차별화의 핵심 장치.
- **"패턴이 아니라 소재"** 논리로 경쟁사 아웃솔 패턴 어필을 무력화.
- **네이밍 브랜딩:** ZERO GRIP, Quick Fit, TECH POINT 01~05 → 기능에 이름을 붙여 기술력 인상.
- **가격 정당화:** "세상에서 가장 저렴한 낙상예방 프로젝트", 리뷰 속 "발목 부러지는 것보단 낫다".
- **신뢰 장치 다수:** N배송, 프리미엄 스토어, 공식판매처 인증마크, 방송 로고, 11년·10만족, 만족도 98%·4.87, 성적서 QR.
- **크로스셀:** 상세 최상단에 인솔 추가구매 링크 → 객단가↑ + 교체 수요 확보.
- **채널:** 숏클립(인플루언서 '명규' 협업), 인스타그램, 체험단형 장문 리뷰 상위 노출.
