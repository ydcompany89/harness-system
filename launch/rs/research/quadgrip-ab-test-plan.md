# 쿼드그립 A/B 미끄럼 시험 설계안 — "논문 + 우리 데이터" 2단 신뢰 구조

> 논문은 **설계 원리**를 뒷받침할 뿐, "쿼드그립이 미끄럼을 줄인다"는 말은 **우리 제품 시험 데이터**가 있어야 쓸 수 있다 (표시광고법).
> 그래서 C02 미끄럼 시험을 **패드 있음/없음 비교**로 설계해, 쿼드그립의 효과를 자체 수치로 확보한다.

## 1. 시험 구성
| 시료 | 내용 | 목적 |
|---|---|---|
| **A** | RS 조리화 + 쿼드그립 패드 4개 | 최종 제품 성능 |
| **B** | 같은 금형, 패드 없음 (헤링본 본체만) | **쿼드그립 기여분** 산출 (A − B) |
| C (선택) | 시판 조리화 1종 | 내부 벤치마크용 — **광고에 경쟁사명 사용 금지** |

- 사이즈: 기관 지정 표준 사이즈(보통 남 260 전후) 각 1족, 예비 1족
- 시료는 **퍼징 후 재사출품**(Q3 얼룩 없는 것), 패드 고정 방식은 양산과 동일

## 2. 시험 조건 (기관과 최종 협의)
| 항목 | 조건 |
|---|---|
| 규격 | ISO 13287 / KS M ISO 13287 (신발 미끄럼 저항, 전체 신발 시험) |
| 바닥·윤활 | ① 세라믹 타일 + 세제수(SLS) ② 스틸 + 글리세린 (기름 바닥 대용) |
| 모드 | 뒤꿈치 전방 미끄럼 / 전족부 후방 미끄럼 / 평면 |
| 산출 | 동마찰계수(CoF) — 조건별 A·B·C 값 |
| (추가) 마모 후 | 마모 시험 후 A 재측정 → "오래 신어도" 근거 (예산 여유 시) |

**시험기관 후보:** 한국신발피혁연구원(부산, 신발 전문) / KATRI / FITI — 견적·소요기간(통상 2~3주)·시사출품 접수 가능 여부 문의
