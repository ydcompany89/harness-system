## 0. 실행 방법

### Claude에게 시킬 때 (권장)
- **"메가쇼 메일 초안 만들어줘"** → `status: ready` 항목마다 **Gmail 임시보관함에 초안**을 만든다. 보내지는 않는다.
- 대표가 Gmail에서 초안을 확인하고 첨부를 확인한 뒤 직접 **보내기**를 누른다.
- 보낸 뒤 **"메가쇼 메일 보냄 처리해줘"** → 해당 항목의 `status`를 `sent`로, `sent_at`에 날짜를 기록한다.
- 바로 발송까지 맡기려면 **"메가쇼 메일 바로 보내줘"**라고 명시한다. 이 경우에도 발송 직전에 목록을 한 번 보여 주고 승인을 받는다.

### 처리 규칙 (INPUT → PROCESS → VALIDATE)
| 단계 | 내용 |
|---|---|
| INPUT | 아래 `## 2. 발송 목록`의 YAML 블록 (`status: ready`인 것만) |
| PROCESS | ① `to`·`cc`·`subject`·`body`로 메일 작성 → ② 본문 끝에 `## 1` 공통 서명 붙이기 → ③ `attachments` 파일 첨부(Gmail 초안 도구가 첨부를 못 하면 '첨부 필요' 목록으로 대표에게 알림) → ④ 초안 저장 또는 발송 |
| VALIDATE | 발송 전에 아래 체크리스트를 모두 통과해야 한다 |

### 발송 전 체크리스트 (하나라도 걸리면 `hold`)
- [ ] 본문에 `[` `]` 빈칸이 남아 있지 않다
- [ ] 받는 사람 이름과 본문 첫 줄 호칭이 같다
- [ ] "의료기기" 문구가 없다 (B2B 메일 규칙, 11/23)
- [ ] 단가·공급가 숫자가 없다 (공급가는 견적서로 — 공동대표 합의 사항)
- [ ] 샘플을 보내겠다는 약속이 없다 (이번 발송은 회사소개서만, 11/23)
- [ ] 첨부 파일이 실제로 붙었다
- [ ] 같은 업체에 이미 보낸 적이 없다 (`status: sent` 확인)
