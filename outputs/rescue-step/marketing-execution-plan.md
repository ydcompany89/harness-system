## 1. B2C/SNS 콘텐츠 캘린더 (4주)

| 주 | 인스타그램 | 유튜브숏폼 |
|---|---|---|
| 1주 | 소재 클로즈업: 타이어 트레드→아웃솔 단면 | "타이어 1개가 신발이 되기까지" 공정 15초 |
| 2주 | 젖은 주방 바닥 접지 테스트 릴스 | 조리사 인터뷰: 미끄럼 사고 경험담 |
| 3주 | 시험성적서 수치 카드뉴스 | 그립달 등장, 제품 언박싱 |
| 4주 | 실사용 조리사 리뷰(UGC) | Q&A: "왜 폐타이어인가" |

**캡션 예시**
1. "타이어 1개 → 주방화 그립. 미끄럼 저항 [등급]. #RESCUESTEP"
2. "젖은 바닥, 기름 바닥. 접지력은 근거로 증명합니다. 시험성적서 링크 프로필에."
3. "1켤레 약 2.5kg CO2 저감 (EPD 기준). 근거는 항상 링크에 있습니다."
4. "앞코 막힌 구조. 조리 현장 그대로 반영했습니다."

원칙: 헤드라인 5어절 이내, 감정 호소어 배제, 수치+출처 동반, 그립달은 B2C 채널에만.

## 2. 와디즈 펀딩 기획 (wadiz-funding 스킬)

**SWOT 요약**: S-차별 소재/근거중심 톤, W-3만원대 진입장벽(노브랜드 대비), O-ESG 가치소비/조리사 커뮤니티, T-크록스 비스트로 등 기존 유통 즉시구매 가능성.

**페르소나**: 25~40세 조리사/급식 종사자·조리전공생, 인스타에서 키친/제로웨이스트 계정 팔로우, "근거 있는 소비" 지향. 3월 이직·개학 시즌 또는 9월 기획전과 매칭 권장.

**목표 역산 (Key값, 보수적 세팅)**
| 항목 | 값 |
|---|---|
| 목표금액 | 15,000,000원 |
| 객단가(얼리버드) | 25,000원 |
| 구매전환 필요수 | 600켤레 |
| 알림신청 전환율 | 5% → 필요 12,000명 |
| 오픈예정 기간 | 20일 → 일당 알림신청 600명 |
| 유입 전환율 | 1% → 총 유입 120만, 일당 6만 |
| 초반 3일 목표(60%) | 9,000,000원 (360켤레) |

**리워드 구성**: 슈퍼얼리버드 25,000원(선착순 100) / 얼리버드 27,000원 / 오리지널 30,000원 / 2켤레 세트 54,000원 / B2B 10켤레 세트 270,000원.

**광고 소재 방향(7요소 체크)**: 제품 한눈에(트레드 클로즈업) / 가격(할인율 명시) / USP(미끄럼저항 수치) / 소비자 베네핏(안전) / 사용환경(실제 주방, 미화 금지) / 시의성(이직·개학) / 사은품 여부는 확정 후 반영.

## 3. B2B 제안 핵심 메시지 (성능 수치 중심, 캐릭터 배제)

1. **접지력**: "미끄럼 저항 계수 [수치], 젖은/기름 바닥 조건 시험성적서 기준" — 산재 리스크를 수치로 설명.
2. **내구성**: 폐타이어 아웃솔 내마모 시험 결과 수치 + 인솔(CXP·EVA 하이브리드) 내구 사이클 수치.
3. **총소유비용**: 3만원대 단가, 대량구매 단가표, 교체 주기 기준 1일 사용비용 환산.

3건 모두 링크(시험성적서/EPD)를 반드시 병기, 절대·최상급 표현 금지.

## 4. 상세페이지 방향 메모 (추후 simple-detail-page 스킬 제작용)

- 1장 Hook은 감성컷 대신 가장 강한 수치(미끄럼 저항 등급) 배치.
- 셀링포인트는 "접지력" 하나로 좁히고, 환경 메시지는 "그런데 심지어" 포지션으로 뒤 배치, 반드시 수치+출처 각주.
- 배경/소재컷은 실제 젖은 주방바닥·트레드 단면만 사용, 초록잎·지구본·파스텔 배경 금지.
- 비교표(자사 vs 일반 주방화)는 특정 브랜드 지목 없이 "시중 일반 제품" 표기.
- 후기 섹션은 실제 구매평 확보 전까지 비우고 사용 가이드로 대체.
