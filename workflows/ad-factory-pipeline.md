# Workflow: 퍼포먼스 광고 소재 팩토리 (역기획 → 스크립트 → 소재생산 → 콘티 → PAUSED 집행)

## INPUT
- 타겟 제품/브랜드명 + 경쟁사 브랜드 후보 리스트 (없으면 Stage 1-A에서 소싱)
- 경쟁 광고 URL 3~5개 (Meta Ad Library 링크 또는 실제 소재 URL — 1-A로 자동 소싱 가능)
- 브랜드/제품 브리프 (알앤디메이커스 업사이클링 욕실화·CXP 소재 제품 · 와이디컴퍼니 캄폿후추 등)
- 표시광고법 금칙어 리스트 (아래 VALIDATE 참고, 발견되는 대로 이 파일에 계속 추가)
- 데이터 로그: `data/ad-factory-script-bank.csv`

## PROCESS

### Stage 1. 경쟁 광고 역기획

#### 1-A. 광고 소싱 (3채널 벤치마킹)
"경쟁사가 광고비를 많이/오래 쓰는 소재 = 수익을 내고 있을 가능성이 높은 소재"라는 전제로,
아래 3채널에서 지속적으로 노출되는 광고를 우선 수집한다.

| 채널 | 방법 | 사용 도구 | 신호 |
|---|---|---|---|
| Meta 광고 라이브러리 | 경쟁사 브랜드명/페이지로 검색, `ad_active_status=ACTIVE`로 필터 | `ads_library_search` (search_terms 또는 page_ids) | 한 페이지가 동시에 돌리는 ACTIVE 소재 개수, 개별 소재의 게재 시작일(오래될수록 유지 중 = 잘 되는 소재일 가능성) |
| 구글 광고 투명성 센터 | 경쟁사 도메인으로 조회 (adstransparency.google.com) | `WebFetch` | 영상 광고 조회수로 대략적 광고비 역산 |
| 네이버 쇼핑 광고 | 타겟 키워드로 쇼핑검색 광고 결과 확인, 동일 업체가 며칠~몇 주 연속 노출되는지 관찰 | `WebFetch` (1회 조회로는 부족 — 최소 며칠 간격 재조회 필요. 주기 모니터링은 `researcher` 서브에이전트와 협업 고려) | 광고를 오래 유지 = 광고 효율이 좋다는 방증 |

⚠️ **주의**: Meta/네이버 모두 정치·이슈 광고와 달리 일반 상업광고는 실제 집행 광고비·노출수가 공개되지 않는다.
"노출순 정렬"이 아니라 **"ACTIVE 소재 개수 + 게재 유지 기간"을 광고비 집행 규모의 대리 신호**로만 쓰고,
이 신호를 실제 광고비/노출수 숫자인 것처럼 보고하지 않는다.

#### 1-B. 씬 단위 분해
1. 1-A에서 수집한 광고 3~5개를 씬 단위로 분해
2. 추출 항목 (고정 포맷):
   - 훅 타이밍(초) — 첫 훅이 몇 초 지점에 배치됐는지
   - 첫 3초 카피 — 정확한 워딩
   - 컷 전환 리듬 — 평균 컷 길이/패턴
   - CTA 위치 — 영상의 몇 % 지점에 등장하는지
   - 소구 유형 — 고통자극형/욕망변화형/사회적증거형 중 분류
3. 결과를 `소재ID` 없이 역기획 원자료로만 정리 (Stage 2 입력용)

### Stage 2. 스크립트 생성
1. Stage 1 역기획 결과 + DR 카피 3종(고통자극형/욕망변화형/사회적증거형)을 조합
2. 스크립트 10개 세트 생성, 각 60초 이내
3. **표시광고법 금칙어 필터** (자동 적용, 통과 못하면 재작성):
   - 최상급/단정 표현: "최고", "유일", "1위", "완치", "100%", "무조건", "전혀 없음" 등
   - 근거 없는 수치 단정 ("~% 개선" 같은 표현은 실측 데이터 없으면 배제)
4. 통과한 스크립트마다 `소재ID` 발급 (`ADF-YYYYMMDD-순번` 형식 권장) 후
   `data/ad-factory-script-bank.csv`에 상태=`초안`으로 즉시 로깅
5. ⚠️ 방향성(소구 유형·훅 타이밍·CTA 위치)만 제시하고 표현 자체는 AI에게 위임한다 —
   대사 한 줄 한 줄을 사람이 지정하는 과도한 세부 통제는 하지 않는다

### Stage 3. 소재 생산 (영상 베리언트)
1. 스크립트당 영상 베리언트 1~2개 배치 생성
2. **1회 실행당 최대 12개까지만** (스크립트 10개 × 1.2개 평균 등으로 상한 준수)
3. 생성 완료된 소재는 CSV 상태를 `생성완료`로 갱신

### Stage 4. 비트컷 콘티 출력
1. 소재 + TTS를 1초 단위 비트컷(Beat Cut) 타임라인 표로 출력
2. 캡컷(CapCut) 임포트 기준 포맷 (타임코드 / 컷 내용 / TTS 대사 / 자막 여부)
3. ⚠️ 억지 자막 넣지 말 것 — 원본 영상을 1초 단위로 쪼개는 비트컷 스타일 유지, 자막은 꼭 필요한 경우만

### Stage 5. 집행 (Meta Ads 업로드)
1. Meta Ads에 캠페인/광고세트/광고 생성 시 **상태값은 반드시 PAUSED로 고정**
2. 업로드 완료 시 CSV 상태를 `PAUSED업로드`로 갱신
3. ⚠️ **ACTIVE 전환은 절대 자체 실행 금지** — 사람이 직접 Meta Ads Manager에서 전환
   - `ads_activate_entity`류 ACTIVE 전환 도구는 애초에 서브에이전트 tools 목록에서 제외되어 있음 (기술적 차단)
4. 사람이 검토 후 승인하면 CSV 상태를 `승인` → 실제 집행 시작되면 사람이 `집행중`으로 갱신 (자동 갱신 아님)

## VALIDATE
- [ ] Stage 1-A에서 수집한 신호(ACTIVE 소재 개수/게재 유지 기간/조회수)를 실제 광고비·노출수인 것처럼 과장 보고하지 않았는가
- [ ] Stage 1~5 모든 산출물이 `data/ad-factory-script-bank.csv`에 로깅되었는가
- [ ] 표시광고법 금칙어(최고/유일/100%/무조건 등)가 카피에 남아있지 않은가
- [ ] 스크립트가 모두 60초 이내인가
- [ ] 소재 생산이 1회 실행당 12개를 넘지 않았는가
- [ ] Meta Ads 업로드가 전부 PAUSED 상태인가 (ACTIVE로 올라간 건 없는가)
- [ ] 콘티에 불필요한 자막이 과도하게 들어가지 않았는가 (비트컷 스타일 유지)
- [ ] 광고비 집행, ACTIVE 전환 등 비가역 액션에 사람 승인 없이 진행된 항목이 없는가
