# Workflow: 라라슈(LARASH) 브랜드 런칭 PM

> 대상 제품: 친환경 조리화(주방화) · 인솔 — 폐타이어 고무칩/CXP 기반 (시사출 완료, 2026-09 기준)
> 마스터 트래커: `launch/larash/checklist.csv` (노션/구글시트로 그대로 import 가능)
> 진행 로그: `launch/larash/log.md`

## INPUT
- 시사출 결과 (사진, 착화 피드백, 불량 포인트, 금형 수정 여부)
- 런칭 목표일 / 1차 판매 채널 (와디즈 · 스마트스토어 · 쿠팡 · 다이소 · B2B 급식) — 미정이면 `[확인필요]`
- 원가 자료: 원자재 단가, 사출 공임, 금형비, 포장비, 물류비
- 새활용 도약 과제 협약서·사업계획서 (예산 비목, 성과지표 KPI, 수행기간)
- 기존 자산: 다이소 거래 관계, 라파 최재호 대표 기술 자문, NTB 특허

## PROCESS

1. **현황 스캔**: `checklist.csv` 를 읽고 상태가 `진행중`/`막힘`인 항목과 마감 D-14 이내 항목을 추린다.
2. **크리티컬 패스 점검**: 아래 의존관계를 기준으로 "지금 안 하면 런칭일이 밀리는 것"부터 정렬한다.
   ```
   시사출 평가 → 금형 수정 → 시험성적서(미끄럼/내유) → 친환경·기능 표시 문구 확정
                                                  ↘ 상세페이지/광고 카피
   상표 출원 ─────────────────────────────────────→ 패키지 인쇄 발주
   원가표(BOM) → 채널별 가격표 → 양산 발주(MOQ) → 입고 → 판매 오픈
   도약 과제 예산 비목 확인 → 시사출·시험비 집행 증빙 → e나라도움 정산
   ```
3. **영역별 위임 라우팅** (팀장이 이 표대로 서브에이전트/스킬에 넘긴다):

   | 영역 | 담당 | 활용 스킬/커넥터 |
   |---|---|---|
   | 브랜드(BI·브랜드북·패키지) | content-creator | `brand-kit-builder` |
   | 상세페이지·썸네일·SEO 상품명 | content-creator | `simple-detail-page` |
   | 펀딩 기획·목표금액 역산 | content-creator | `wadiz-funding` |
   | 숏폼(비트컷)·DR 카피 10종 | content-creator | CLAUDE 사용자 지침 Rule 2 |
   | 시장·경쟁사·키워드 조사 | researcher | 네이버 데이터랩, 나라장터 검색 |
   | B2B 급식사·조달 제안서, 다이소 MD 제안 | sales-ops | 제안서 = ESG·탄소감축 수치 요약표 |
   | 일정·마감 리마인드 | daily-assistant | Google Calendar |
   | 원가·가격·손익, 정부과제 집행 | **larash-launch-pm 직접** | `xlsx`, `rndmakers-ledger-entry` |

4. **주간 브리핑 작성**: `log.md` 에 날짜별로 누적 (형식은 아래 VALIDATE 참고).
5. **트래커 갱신**: 완료/신규 항목을 `checklist.csv` 에 반영. 항목 삭제 금지 — 불필요해지면 상태를 `보류`로.

## 절대 규칙 (리스크 방어)
- **"친환경/탄소감축/미끄럼방지" 표현은 근거 자료 ID 없이 카피에 쓰지 않는다.**
  환경성 표시·광고 관리제도 + 표시광고법 위반 시 과징금·판매중지 리스크. 근거 = 시험성적서, GR/환경표지 인증, LCA 계산서.
- 정부지원금(도약 과제) 집행은 **협약 비목·수행기간 안에서만** 제안한다. 비목 외 집행 제안 금지.
- 금액이 확정되는 모든 것(양산 발주, 가격표, 광고 예산, 지원금 집행)은 `사람승인` 컬럼 = `필요` 로 표시하고 대표님 확인 전 확정본 금지.
- 상표 출원 전에는 "라라슈" 로고를 인쇄물(패키지·금형 각인)에 확정 반영하지 않는다.

## VALIDATE
- [ ] 브리핑 첫 줄이 "이번 주 반드시 할 3가지"로 시작하는가 (각 항목에 담당·마감일 포함)
- [ ] 막힘(`막힘`) 항목마다 "누가 무엇을 주면 풀리는지" 한 줄이 있는가
- [ ] D-14 이내 마감 항목이 전부 브리핑에 노출됐는가
- [ ] 친환경·기능성 표현이 들어간 산출물에 근거 자료 ID가 달려 있는가
- [ ] 금액 확정 항목에 `사람승인: 필요` 표시가 빠지지 않았는가
- [ ] `checklist.csv` 가 CSV로 깨지지 않는가 (컬럼 수 동일, 쉼표 포함 값은 따옴표)
