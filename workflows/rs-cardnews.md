# Workflow: 자영업자 정보형 카드뉴스 (RHARA SHOE 인스타 캐러셀)

> 목적: 서서 일하는 자영업자(식당·카페·매장·급식)에게 **저장·공유되는 정보**로 유입 → 프로필 → 알림신청/구매.
> 원칙: 정보 90% · 브랜드 10% (마지막 장 로고 한 줄만). 판매 문구·가격·효능 ✗.
> 담당: 기획 marketing-expert → 제작 rs-brand-designer → 감수 rs-compliance → 대표 승인(L2, 게시)

## INPUT
- 주제 1개 (아래 주제 은행) · 근거 (일반 상식/공식 자료 — 통계는 출처 필수)
- `launch/rs/design/cardnews/sets/<번호-주제>.json` (표지 · 항목 3~7 · 끝장)

## PROCESS
1. 주제 선정 — 저장할 이유가 있는가? ("체크리스트 · 순서 · 기준" 형태)
2. JSON 작성 — 제목 2줄 이내 · 본문 2줄 이내 · 항목마다 행동 팁 1줄(☐)
3. `python3 build.py sets/<파일>.json` → `out/<id>/01~NN.png` (1080×1350)
4. 감수: 금지 표현(product-master.md) · 건강 효능 단정 ✗ · 통계 출처
5. 대표 승인 → 게시 (화·토 오전) · 캡션 첫 줄 = 표지 제목 · 해시태그 5개
6. 2주 뒤 저장 수·공유 수 기록 (구글시트 KPI 탭 메모)

## VALIDATE
- [ ] 표지만 보고 "저장해야겠다"가 드는가
- [ ] 한 장당 메시지 1개 · 본문 40pt 이상
- [ ] 효능·의학 표현 0 · 가격·할인 0 · 타사 비방 0
- [ ] 끝장: 체크리스트 요약 + 저장/공유 CTA + 로고 한 줄
- [ ] 표기 RHARA SHOE · 구 슬로건(서서 일하는 하루를 위해) ✗
