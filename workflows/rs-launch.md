# Workflow: RS 브랜드 런칭 PM (1차 RS 11/1 → 2차 라라슈 12월~)

> **브랜드 구조**: 대표 브랜드 **RS** (모든 마케팅 통일) / RS 풀네임 **리솔앤슈(Re sole & shoe)** — 상세페이지에만 사용 / 서브 브랜드 **라라슈** (12월 준비 착수)
> **시사출 품평**: `launch/rs/qc/` (결함 리스트 Q1~Q10, 사진)
> **1차 런칭일: 2026-11-01(일)** — 제품: 친환경 조리화(주방화) · 인솔 (폐타이어 고무칩/CXP, 시사출 완료)
> **11/1 전 필수 완료 3종**: ① 상품 패키지 ② 상세페이지 ③ 홈페이지
> 마스터 트래커: `launch/rs/checklist.csv` (노션/구글시트 import 가능) · 진행 로그: `launch/rs/log.md`

## INPUT
- 시사출 결과 (사진, 착화 피드백, 불량 포인트, 금형 수정 여부)
- 원가 자료: 원자재 단가, 사출 공임, 금형비, 포장비, 물류비
- 새활용 도약 과제 협약서·사업계획서 (예산 비목, 성과지표 KPI, 수행기간)
- 기존 자산: 다이소 거래 관계, 라파 최재호 대표 기술 자문, NTB 특허

## PROCESS

1. **현황 스캔**: `checklist.csv` 에서 상태가 `진행중`/`막힘`인 항목, 마감 7영업일 이내 항목을 추린다.
2. **크리티컬 패스 점검** (11/1 역산 — 이 순서가 깨지면 즉시 브리핑 최상단에 경고):
   ```
   [브랜드] RS 아키텍처·로고 확정(10/2) → 상표 출원(10/6) ─┐
   [패키지] 구조·사이즈(10/2) → 시안(10/8) → 인쇄데이터(10/12) → 발주(10/13) → 입고(10/26)
   [상세]   촬영(10/14~16) → 카피(10/16) → 시안(10/21) → 시험결과 반영 최종(10/27)
   [홈피]   도메인·플랫폼(9/30) → 사이트맵(10/2) → 원고(10/20) → 제작(10/27) → QA·오픈(10/30)
   [제품]   금형수정(10/2) → MOQ·리드타임(10/7) → 판매방식 결정(10/7) → 발주(10/12) → 입고(10/28)
   [근거]   시험 의뢰(10/2) → 성적서(~10/23) → 표현 가이드(10/19 초안, 10/23 확정) → 상세·패키지 문구
   ```
3. **영역별 위임 라우팅**:

   | 영역 | 담당 | 활용 스킬/커넥터 |
   |---|---|---|
   | RS 브랜드(BI·브랜드북·패키지 디자인) | content-creator | `brand-kit-builder` |
   | 상세페이지·썸네일·SEO 상품명 | content-creator | `simple-detail-page` |
   | 홈페이지 원고·구조 | content-creator | (플랫폼 결정 후 제작) |
   | 숏폼(비트컷)·DR 카피 10종 | content-creator | 사용자 지침 Rule 2 |
   | 시장·경쟁사·키워드·상표 선행조사 | researcher | 네이버 데이터랩, KIPRIS |
   | B2B 급식사·조달·다이소 제안서 | sales-ops | ESG·탄소감축 수치 요약표 |
   | 일정·마감 리마인드 | daily-assistant | Google Calendar |
   | 원가·가격·손익, 정부과제 집행 | **rs-launch-pm 직접** | `xlsx`, `rndmakers-ledger-entry` |

4. **주간 브리핑 작성**: `log.md` 에 날짜 역순 누적.
5. **트래커 갱신**: 완료/신규 항목 반영. 삭제 금지 — 불필요하면 `보류`.

## 절대 규칙 (리스크 방어)
- **1차 산출물은 전부 RS.** 풀네임 '리솔앤슈(Re sole & shoe)'는 상세페이지 브랜드 스토리에만. 라라슈는 홈페이지 "Coming soon" 자리와 상표 출원 외에는 노출 금지.
- **"친환경/탄소감축/미끄럼방지" 표현은 근거 자료 ID 없이 쓰지 않는다.**
  환경성 표시·광고 관리제도 + 표시광고법 위반 시 과징금·판매중지 리스크. 성적서가 11/1 전에 안 나오면
  해당 문구를 빼고 오픈 → 성적서 수령 후 상세페이지 업데이트.
- 패키지는 **인쇄 후 수정 불가** → 인쇄데이터 확정(10/12) 전 품질표시·바코드·사업자정보·재질표시를 VALIDATE 표로 1:1 대조.
- 정부지원금(도약 과제) 집행은 **협약 비목·수행기간 안에서만** 제안한다.
- 금액이 확정되는 모든 것(양산 발주, 인쇄 발주, 가격표, 광고 예산, 지원금 집행)은 `사람승인 = 필요`.

## VALIDATE
- [ ] 브리핑 첫 줄이 "D-xx / 이번 주 반드시 할 3가지"로 시작하는가 (담당·마감 포함)
- [ ] 패키지·상세페이지·홈페이지 3종 진행률이 매 브리핑에 들어가는가
- [ ] 막힘 항목마다 "누가 무엇을 주면 풀리는지" 한 줄이 있는가
- [ ] 7영업일 이내 마감 항목이 전부 브리핑에 노출됐는가
- [ ] 1차 산출물에 라라슈 명칭이 섞이지 않았는가
- [ ] '리솔앤슈' 풀네임이 상세페이지 외(광고·패키지·홈피 메인)에 쓰이지 않았는가
- [ ] 친환경·기능성 표현이 들어간 산출물에 근거 자료 ID가 달려 있는가
- [ ] 패키지 인쇄 전: 품명·재질·치수·제조국·제조자/수입자·주소·연락처·바코드·분리배출 표시 확인
- [ ] 홈페이지 오픈 전: 사업자정보·통신판매업 신고번호·개인정보처리방침·이용약관 게시
- [ ] 금액 확정 항목에 `사람승인: 필요` 표시가 빠지지 않았는가
- [ ] `checklist.csv` 컬럼 수가 모든 행에서 동일한가
