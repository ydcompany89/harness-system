# Workflow: SNS 콘텐츠 퍼널 (인스타그램 · 유튜브 쇼츠)

> SNS = 팔로워 숫자가 아니라 **사업의 입구**. 모든 콘텐츠는 아래 3가지 역할 중 하나를 맡는다.
> 담당 서브에이전트: `sns-content-planner` · 현재 적용 브랜드: RS(RhaRa Shoe·라라슈)

## 3가지 콘텐츠 역할

| 역할 | 목적 | 형식 | 성공 지표 |
|---|---|---|---|
| **① 유입** | 브랜드를 모르는 사람에게 노출 | 고객이 궁금해할 **정보성 주제** (제품 홍보 X) | 도달·3초 유지율·저장 |
| **② 설득** | 왜 이 브랜드여야 하는지 신뢰 | 만든 이유·비하인드·**PS 구조(Problem→Solution)**·후기·전문가 | 프로필 방문·팔로우·DM |
| **③ 전환** | 마지막 망설임 제거 → 결제 | 구매 안내·사용법·사이즈·FAQ·할인 공지 → **프로필 링크** | 링크 클릭·구매 |

## INPUT
- 브랜드·제품 정보 (`launch/<브랜드>/` 트래커·리서치·행택 문안)
- 고객 질문 소스: 최근 3개월 DM·문의·리뷰·박람회 질문 (없으면 네이버 지식인·카페·경쟁 제품 저평점 리뷰)
- 현재 단계: 런칭 전 / 런칭 주 / 런칭 후 / 행사 기간
- 지난주 지표 (있으면)

## PROCESS
1. **단계별 비율 정하기** (주 3~4편 기준)
   | 단계 | 유입 | 설득 | 전환 |
   |---|---|---|---|
   | 런칭 전 | 2 | 1 | 0 (알림신청만) |
   | 런칭 주 | 1 | 1 | 2 |
   | 런칭 후 상시 | 2 | 1 | 1 |
2. **주제 뽑기 — 빈 캔버스 금지.** 아래 소스에서만 뽑고 소스를 표기한다.
   - 유입: 고객 궁금증 / AI 브레인스토밍(30개 → 대표 경험 붙일 수 있는 5개) / 반복 문의 / 현장 불편 상황
   - 설득: 만든 이유(대표 이야기) / 개발·품평·수정 비하인드 / PS 구조 / 체험단 후기 / 전문가 자문
   - 전환: 구매 망설임 TOP 질문(사이즈·세척·배송·교환) / 사용법 / 세트·할인 공지 / 구매 후기
3. **제목**: "○○하는 분들"처럼 타깃의 실제 상황을 짚는다. 전문가식 제목 금지.
4. **콘티**: 1초 단위 비트 컷 (시간 | 화면 | 자막 | 소리). 첫 1초 = 상황 훅. 억지 자막 금지. 폰 촬영 B급 OK.
5. **연결 동선**: 유입 캡션 → 고정 게시물/하이라이트(설득) → 프로필 링크(전환). 모든 콘텐츠에 다음 단계 CTA 1개.
6. **주간 리뷰(금)**: 지표 확인 → 반응 좋은 주제는 시리즈화, 3초 유지율 낮으면 첫 1초 교체.
7. 결과는 `launch/<브랜드>/content/` 에 주차별로 누적.

## 표시광고 가드 (모든 역할 공통)
- 유입 정보성 → **우리 제품 효과로 연결 금지** ("그래서 우리 신발은 안 미끄러져요" ❌)
- 미끄럼방지·충격흡수·방수·교정·통증·재활용 % 등은 근거(성적서·계산서) 확보 전 금지
- 후기·자문 출연 시 "제품 제공/자문료" 표기, 경쟁 브랜드명 노출 금지
- 통계·논문 인용은 출처 1줄, DOI 대조 완료분만

## VALIDATE
- [ ] 콘텐츠마다 역할(유입/설득/전환)과 주제 소스가 표기됐는가
- [ ] 이번 주 비율이 현재 단계 표와 맞는가
- [ ] 제목이 현장 상황형인가
- [ ] 1초 단위 콘티 + 캡션 + CTA 1개가 모두 있는가
- [ ] 표시광고 가드 위반 문구가 없는가
- [ ] 전환 콘텐츠의 링크·가격·할인 조건은 사람 승인을 받았는가
