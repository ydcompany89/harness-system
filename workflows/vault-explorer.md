# Workflow: 2번째뇌 볼트 탐색기 (vault-explorer)

옵시디언 볼트 "동규2번째뇌"를 그래프/계층 뷰로 탐색하는 읽기 전용 도구.
파일: `vault-explorer/explorer.html`, `vault-explorer/build_index.py`, `vault-explorer/update_index.bat`

## INPUT
- 옵시디언 볼트 폴더 (전체 `.md`)
- 제외: `.obsidian/`, `_resources/`, 점(.)으로 시작하는 폴더(.trash, .git 등), 탐색기 폴더 자체

## PROCESS
1. **설치(최초 1회)**: `vault-explorer` 폴더를 통째로 볼트 루트 바로 아래에 복사
   → 그러면 경로 설정 없이 자동 탐지됨. (볼트 밖에 둘 거면 `build_index.py` 상단 `VAULT_PATH` 에 경로 기입)
2. **인덱스 갱신**: `update_index.bat` 더블클릭 (또는 `python build_index.py "볼트경로"`)
   - 생성: `vault-index.json`(메타) · `vault-index.js`(더블클릭용) · `vault-content.js`(미리보기/본문검색용)
   - 노트 추출 항목: 경로 · 제목 · 폴더 · 프론트매터 태그(+본문 #태그) · [[위키링크]] · 본문 앞 300자 · 수정일
3. **열기**: `explorer.html` 더블클릭 (인터넷 필요 — d3/marked/DOMPurify CDN)
4. 노트를 많이 고친 날은 2번만 다시 실행 → 브라우저 새로고침

### 사용 팁
| 기능 | 방법 |
|---|---|
| 검색 | `/` 키 → 제목·본문·태그 동시 검색, 띄어쓰기 = AND, `#태그` = 태그 검색, `is:고아` = 고아만 |
| 태그 하이라이트 | 상단 칩 클릭 (여러 개 = OR). `＋ 태그` 로 다른 태그 칩 추가 |
| 폴더 범위 | 좌측 폴더에 마우스 → `⌖` 클릭, 또는 그래프 범례 클릭 |
| 고아 노트 | `고아 노트` 버튼 = 표시/숨김 토글. 그래프에서 속이 빈 원 = 고아 |
| 그래프 | 드래그=노드 이동, 휠=줌, 더블클릭=확대, `⤢ 맞춤`=전체보기 |
| 계층 뷰 | 폴더 이름 클릭 → 확대, 상단 경로로 복귀. 칸 크기 = 본문 분량 |
| 해제 | `Esc` = 검색어 → 태그 → 선택 순서로 해제 |

## VALIDATE
- [ ] 인덱싱 후 원본 `.md` 수정일/해시가 바뀌지 않았는가 (스크립트는 `.md` 쓰기 시 즉시 중단하는 안전장치 있음)
- [ ] 콘솔 출력의 노트 수가 옵시디언 파일 수와 대략 맞는가 (`.obsidian`/`_resources` 제외분 감안)
- [ ] "미해결 링크" 수가 갑자기 늘었으면 → 파일명 변경으로 링크가 깨진 것. 미리보기 하단 `(노트 없음)` 목록에서 확인
- [ ] 생성물(vault-index.*, vault-content.js)은 볼트 내용 전체가 들어있음 → **git 커밋/외부 공유 금지** (.gitignore 처리됨)

## 알려진 한계 / 개선 후보
- 옵시디언 별칭(aliases)으로만 건 링크는 해석하지 않음 (옵시디언 기본 동작과 동일)
- 첨부 이미지(`![[사진.png]]`)는 미리보기에 이름만 표시
- 오프라인에서 쓰려면 CDN 3개 파일을 내려받아 `<script src>` 를 로컬 경로로 바꾸면 됨
